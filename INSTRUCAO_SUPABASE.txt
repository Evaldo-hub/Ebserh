🚀 INSTRUÇÕES PARA CONFIGURAR O SUPABASE - EBSERH STUDY APP

✅ APLICAÇÃO ESTÁ RODANDO EM: http://127.0.0.1:5000

📋 PRÓXIMOS PASSOS:

1️⃣ ACESSAR O PAINEL SUPABASE:
   - Vá para: https://supabase.com/dashboard
   - Faça login com sua conta
   - Selecione o projeto: aiczalggetwcymzdflme

2️⃣ CRIAR AS TABELAS:
   - No painel, clique em "SQL Editor"
   - Copie e cole o SQL abaixo:

   CREATE TABLE IF NOT EXISTS questoes (
       id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       id_local INTEGER UNIQUE,
       disciplina TEXT NOT NULL,
       semana INTEGER NOT NULL,
       nivel TEXT NOT NULL CHECK (nivel IN ('Básico', 'Alto', 'Pegadinha')),
       banca TEXT NOT NULL,
       enunciado TEXT NOT NULL,
       alternativas TEXT NOT NULL,
       resposta_correta TEXT NOT NULL,
       comentario TEXT NOT NULL,
       data_sincronizacao TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );

   CREATE TABLE IF NOT EXISTS desempenho (
       id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       id_local INTEGER UNIQUE,
       questao_id_local INTEGER NOT NULL,
       resposta_usuario TEXT NOT NULL,
       acerto BOOLEAN NOT NULL,
       data_resposta TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       data_sincronizacao TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );

   CREATE TABLE IF NOT EXISTS plano_estudos (
       id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       id_local INTEGER UNIQUE,
       semana INTEGER NOT NULL UNIQUE,
       conteudo TEXT NOT NULL,
       disciplinas TEXT NOT NULL,
       data_sincronizacao TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );

   CREATE TABLE IF NOT EXISTS ia_feedback (
       id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       id_local INTEGER UNIQUE,
       questao_id_local INTEGER NOT NULL,
       tipo TEXT NOT NULL,
       conteudo TEXT NOT NULL,
       utilidade INTEGER DEFAULT 0,
       data TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       data_sincronizacao TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );

3️⃣ EXECUTAR O SQL:
   - Clique em "RUN" para executar
   - Aguarde a mensagem "Success"

4️⃣ TESTAR A INTEGRAÇÃO:
   - Acesse: http://127.0.0.1:5000/supabase
   - Clique em "Testar Conexão"
   - Deve aparecer "Conexão estabelecida com sucesso"

5️⃣ SINCRONIZAR DADOS:
   - Após criar as tabelas, clique em "Sincronizar Tudo"
   - Aguarde o processo completar
   - Verifique os logs e estatísticas

🔧 OPÇÕES DISPONÍVEIS NA INTERFACE:

• Testar Conexão - Verifica comunicação com Supabase
• Criar Tabelas - Gera SQL para criação manual
• Corrigir Tabelas - Gera SQL para corrigir tabelas existentes
• Sincronizar Tudo - Envia questões, desempenho, plano e feedback
• Sincronizar Apenas Questões - Apenas tabela questoes
• Sincronizar Apenas Desempenho - Apenas tabela desempenho
• Sincronizar Plano de Estudos - Apenas tabela plano_estudos
• Sincronizar IA Feedback - Apenas tabela ia_feedback
• Atualizar Estatísticas - Recarrega contadores

🚨 SE OCORRER ERRO DE COLUNA ID_LOCAL:

Se durante a sincronização aparecer erro "column id_local does not exist":

1️⃣ Clique em "Corrigir Tabelas" na interface
2️⃣ Copie o SQL gerado
3️⃣ No painel Supabase → SQL Editor
4️⃣ Cole o SQL e clique em "RUN"
5️⃣ Aguarde "Success"
6️⃣ Tente sincronizar novamente
